🎯 Core Loss Functions in Neural Networks

Mathematical definitions and gradient formulations used for forward loss calculation and backpropagation.

Binary Cross-Entropy (BCE)

Used for binary classification tasks (e.g., Distinction vs. Regular student performance).

L = - (1/m) * Σ [y*log(ŷ) + (1-y)*log(1-ŷ)] Gradient w.r.t logits (z): ∂L/∂z = ŷ - y
Categorical Cross-Entropy

Used with Softmax for multi-class classification problems.

L = - (1/m) * Σ Σ [y_ik * log(ŷ_ik)] Gradient with Softmax output: ∂L/∂z_i = ŷ_i - y_i
Mean Squared Error (MSE)

Used for continuous numerical regression tasks.

L = (1 / 2m) * Σ (ŷ - y)² Gradient w.r.t predictions: ∂L/∂ŷ = (1/m) * (ŷ - y)
